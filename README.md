# Осторожно, хрупкое! (Handle With Care)

2D-гонка с видом сбоку в духе Hill Climb Racing. Ты ведёшь пикап по бесконечным холмам, а в открытом кузове лежат **три хрупких ящика**. Чем дальше уедешь, тем больше счёт, но холмы становятся круче, а ящики не любят жёстких приземлений.

Стек: **TypeScript + Phaser 4 (Matter.js) + Vite + GitHub Pages**. Вся графика рисуется кодом, внешних картинок нет.

Проект сделан на основе стартового шаблона курса **«Проектирование и разработка игровых приложений»**. Задание: [`ASSIGNMENT_01.md`](./ASSIGNMENT_01.md).

## 1. Правила

- Пикап на мягкой подвеске едет по процедурной трассе: каждый заезд холмы новые.
- Ящики свободно лежат в кузове. Сильный удар — **трещина**, второй сильный удар — ящик **разбит**. Выпал из кузова — **потерян**.
- Поражение: в кузове не осталось ни одного ящика **или** машина лежит на крыше 2 секунды.
- Счёт = пройденные метры + бонус за довезённые ящики (целый +50, треснувший +20).
- Рекорд сохраняется в браузере (localStorage), на трассе его отмечает флажок.

## 2. Управление

| Действие | Клавиатура | Телефон / мышь |
|---|---|---|
| Газ | `→` или `D` | правая половина экрана |
| Тормоз и задний ход | `←` или `A` | левая половина экрана |
| Старт / ещё раз | `Пробел` | касание / клик |

В воздухе газ наклоняет машину назад, тормоз — вперёд: так можно выровняться перед приземлением.

## 3. Как запустить

Нужны **Node.js 22 LTS** (или >= 20.19) и **Git**.

```bash
npm install
npm run dev
```

Vite напечатает адрес, обычно `http://localhost:5173/`. Открой его в браузере.

Проверка типов: `npm run typecheck`.

**Настройка ощущений** — все параметры физики, баланса, камеры и палитры собраны в `src/game/constants.ts` с комментариями.

## 4. Проверка production build

Перед публикацией:

```bash
npm run build
```

Если команда завершилась без ошибок, итоговая версия находится в папке `dist/`.

Её можно проверить локально:

```bash
npm run preview
```

## 5. Публикация на GitHub Pages

В репозитории уже есть workflow:

```text
.github/workflows/deploy.yml
```

После push в ветку `main` GitHub автоматически собирает проект.

Для первого включения Pages:

1. открой репозиторий на GitHub;
2. **Settings → Pages**;
3. в **Build and deployment → Source** выбери **GitHub Actions**;
4. открой вкладку **Actions** и дождись успешного `Deploy to GitHub Pages`;
5. ссылка на игру появится в deployment и в разделе Pages.
